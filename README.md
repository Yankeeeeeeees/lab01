## Ответы на вопросы

**1. Чем `Console.Write()` отличается от `Console.WriteLine()`?**
`Console.Write()` выводит текст и остаётся в той же строке, а `Console.WriteLine()` выводит текст и переводит курсор на новую строку.

**2. Что произойдёт, если присвоить переменной типа `int` значение `3.14`?**
Компилятор выдаст ошибку, так как `3.14` имеет дробную часть, а `int` хранит только целые числа. Для сохранения дробной части нужен тип `double`.

**3. Почему `10 / 3` в C# даёт `3`, а не `3.333...`?**
Оба операнда имеют тип `int`, поэтому результат тоже целый, и дробная часть отбрасывается. Чтобы получить дробный результат, хотя бы один операнд нужно привести к `double`: `10.0 / 3` или `(double)10 / 3`.

**4. Что означает `var` в C# и чем он отличается от динамической типизации в Python?**
`var` означает, что компилятор сам выводит тип переменной по значению, например `var x = 5;` станет `int`. Тип определяется один раз и больше не меняется. В Python переменная может в любой момент начать хранить значение другого типа, а в C# тип фиксирован.

**5. На каких проектах и компаниях используется C# и .NET?**
- **Unity**: один из самых популярных игровых движков, скрипты в нём пишутся на C#.
- **Stack Overflow**: крупнейший сайт вопросов и ответов для программистов построен на .NET.
- **Visual Studio**: основная IDE Microsoft для разработки на .NET и C#.
